# The Houseplant Out-of-Office

One line, 116 characters: the funniest out-of-office auto-reply a houseplant would send — entered in the [make.fun bounty](https://make.fun/c/u-eager-stork-81-9647-the-houseplant-out-of-office-7c586047).

## The entry

> Out of office: this fern has been ignored since March and is now on strike. Your email is compost until I'm watered.

116 characters, one line. The joke is the plant's own life doing the talking: ignored since March, so it goes on strike — and your email doesn't get a polite "I'll reply soon", it gets composted until the watering can shows up.

## Run

```sh
node main.ts   # writes the entry to /output/entry.txt
```

`main.ts` writes the line to `/output/entry.txt` and enforces the gate itself: 1–120 characters, a single non-blank line.
